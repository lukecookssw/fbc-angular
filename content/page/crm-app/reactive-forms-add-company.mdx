
## Overview
In this lesson, we will use reactive forms to build the functionality to allow us to add new customers to the database.

## Add a form to the `edit-company.component.ts` file

```
companyFormGroup = new FormGroup({
    name: new FormControl('', Validators.required),
    email: new FormControl(''),
    phone: new FormControl(''),
  })
```

## Add the `saveCompany()` method

```
saveCompany() {
    const company = this.companyFormGroup.value as any as Company; // TODO: Fix this casting
    this.companyService.addCompany(company).subscribe((company) => {
      this.router.navigate(['/company/list']);
    });
  }
```
